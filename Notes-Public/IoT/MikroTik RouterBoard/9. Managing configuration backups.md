click Files, backup. By default backups are encrypted. Backups contain all the passwords. If you don't want to encrypt, click Don't Encrypt.

Another way to backup is through the terminal. open terminal, 
```terminal
export file=1st_export
```

Now we have 2 files. In order to view the file, move it to our desktop, drag these. One has an extension .backup the other is .rsc. .rsc is a script file. Open the .rsc file with notepad or notebook. You can copy these settings at the terminal.

To restore the backup, click the backup, Restore. write the password, then Restore.
