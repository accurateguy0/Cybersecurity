## Mangle Rules
Mangle rules to mark packets and config queue tree. You'll be able to manage bandwidth for all DHCP clients. Go to IP, Firewall, Mangle. Chain: Forward, In. Interface: the one that is connected to the modem. Go to action, Action: mark connection, New Connection Mark: client-chw-cn, click ok. 
New Mangle Rule, Chain: Forward, Connection Mark: client-dw-con, go to Action, Action: mark packet, New Packet Mark: client-dw-mark. 
Now we're going to do the upload traffic, Chain: prerouting, In. Interface: bridge1, go to action, Action: mark connection, New Connection Mark: client-up-con
 Chain: prerouting Connection Mark: client-up-con In. go to action, Action: mark packet, New Packet Mark: client-up-pk
 Next creating more rules for peer-to-peer traffic. HTTP traffic. Chain: Forward, Protocol: 6(tcp). Any. Port: 80, 443, Packet Mark: client-dw-pk, Connection Mark: , go to action, Action: mark packet, New Packet Mark: http-dw-pk, uncheck Passthrough, to prevent traffic going to this rule going to another rule.
 Chain: Forward, Protocol: 6(tcp). Any. Port: 80, 443, Packet Mark: client-up-pk, Connection Mark: , go to action, Action: mark packet, New Packet Mark: http-up-pk, uncheck Passthrough
 This rule is for peer-to-peer traffic. Chain: Forward, P2P: all-p2p, Packet Mark: client-dw-pk, Connection Mark: , go to action, Action: mark packet, New Packet Mark: p2p-dw-pk, uncheck Passthrough
 This rule is for peer-to-peer traffic. Chain: Forward, P2P: all-p2p, Packet Mark: client-up-pk, Connection Mark: , go to action, Action: mark packet, New Packet Mark: p2p-up-pk, uncheck Passthrough
Create for any other traffic. Chain: Forward, Packet Mark: client-dw-pk, Connection Mark: , go to action, Action: mark packet, New Packet Mark: other-dw-pk, uncheck Passthrough
Create for any other traffic. Chain: Forward, Packet Mark: client-up-pk, Connection Mark: , go to action, Action: mark packet, New Packet Mark: other-up-pk, uncheck Passthrough
## Queue Tree
Go to Queues, we're going to use Queue Tree. Create a Queue. With simple queues they are handled in order. In Queue tree all the queues are processed at the same time, however it requires more configuration. Name: All Bandwidth, Parent: global, Packet Marks: , Limit At: , Max Limit: 10M, Priority: 1.
Name: Download, Parent: All Bandwidth, Packet Marks: client-dw-pk, Queue Type: default-email, Limit At: , Max Limit: 10M, Priority: 2.
For HTTP. Name: http-dw, Parent: Download, Packet Marks: http-dw-pk, Queue Type: pcq-download-default, Limit At: , Max Limit: 10M, Priority: 1.
Name: other-dw, Parent: Download, Packet Marks: other-dw-pk, Queue Type: pcq-download-default, Limit At: , Max Limit: 5M, Priority: 6.
Name: Upload, Parent: All Bandwidth, Packet Marks: http-dw-pk, Queue Type: default-email, Limit At: , Max Limit: 1M, Priority: 8.
