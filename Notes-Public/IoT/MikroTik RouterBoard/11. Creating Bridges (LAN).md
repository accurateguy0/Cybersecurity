Bridge is a ethernet device such as ethernet access point, vlan that can be connected together via Mac Bridge, so bridge allows two separate devices to act as one. Bridge operates in transparent mode, so you won't be able to run traceroute utility, you won't be able to see the bridge show up in that, because you're transparent to the network, so that allows a host on one network to communicate seamlessly with a host on the next network.

Click on Bridge, add a bridge, call this bridge2. Comments allow bridges to be much easier to identify. Clicking on Ports you'll see interfaces connected to bridges. Look at Interfaces. You can choose bridge2 for ether4 and ether5.![[Screenshot_30-4-2026_16177_www.youtube.com.jpeg]]
That's how you create bridges.
