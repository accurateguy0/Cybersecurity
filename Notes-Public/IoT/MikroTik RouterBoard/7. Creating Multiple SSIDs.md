SSID is the technical name for a Wi-Fi network, it is a name you select on your phone or computer to cnnect to wireless internet. 

Before starting you need to have wlan, by connecting to the modem with port 1.

connect to your router, click Wireless. interfaces. Click plus sign, virtual. Ensure the mode is ap bridge, master interface is the same as the name before. SSID: guest. click Aply. Create another one SSID: kid. Click on Security Profile. Call this one guest. Authentification type: WPA PSK and WPA2 PSK. Create another one, name: mykids, the same authentification type. Rename to guestAP and kidsAP.

Let's assign each security config to each virtual access points. click on the security profile, choose guest, click apply, ok. same with mykids.

Add these access points to the bridge. Click on Bridge, click plus sign. Interface: guestAP and do this for kidsAP too. click apply, ok.
